## 3. Тэргүүлэх зэрэг (Priority)

| Зэрэг | Утга | Хариу үйлдэл |
|---|---|---|
| **P0** | Яаралтай — хугацаа хэтэрвэл гэрээ/орлого алдана | Өнөөдөр эсвэл маргааш үйлдэл хийнэ |
| **P1** | Өндөр — гэрээт үүрэг, орлогын шууд эх үүсвэр | Энэ долоо хоногт |
| **P2** | Дунд — хөгжүүлэлт, түншлэл, дараагийн улирлын суурь | 2–4 долоо хоног |
| **P3** | Бага — сайжруулалт, судалгаа | Боломж гарвал |

**WIP хязгаар:** Нэг эзэн зэрэг **3-аас илүү** `🔵 Явцад` таск барихгүй. Илүү гарвал шинэ таск эхлүүлэхийн оронд гацсаныг чөлөөлнө.

## 5. Долоо хоногийн зан үйл (ritual)

| Хэзээ | Юу | Хугацаа |
|---|---|---|
| **Даваа 09:30** | Долоо хоногийн төлөвлөлт — бүртгэлийг гүйлгэж, энэ долоо хоногийн P0/P1-ийг тогтооно | 30 мин |
| **Өдөр бүр** | Блоклогдсон таск бүрийг шалгах: блок арилсан уу? | 5 мин |
| **Баасан 16:00** | Хаалт — дууссаныг тэмдэглэж, хугацаа хэтэрсний шалтгааныг бичнэ | 20 мин |

## 6. Таск нэмэх дүрэм

Шинэ таск бүр дараах 5 талбартай байна, дутуу бол таск биш — санамж:

1. **Юу** — үр дүн нь баримтаар шалгагдахаар (жишээ: "санал хүргүүлсэн", "гэрээ гарын үсэг зурагдсан")
2. **Хэн** — нэг хүн (баг биш)
3. **Хэзээ** — тодорхой огноо
4. **Дараагийн алхам** — хамгийн ойрын нэг үйлдэл
5. **Хамаарал** — өмнө нь юу дуусах ёстой вэ
